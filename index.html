Web アプリDB 設計フェス好き

はじめまして、Ryota です。ソフトウェア開発を学びながら、Web アプリケーションの制作に取り組んでいます。

Java（Servlet / JSP）＋ MySQL によるサーバーサイド開発から学び始め、現在は HTML / CSS / JavaScript でのフロントエンド実装にも幅を広げています。

原動力はライブ・フェス。「自分が欲しいものを、自分の手で作る」をテーマに、ライブ参戦を管理するアプリ「LivePlan」を開発しました。

STEP 01

Java と MySQL でサーバーサイド開発を学習

MVC・レイヤー構成・トランザクションなど、Web アプリの基礎を習得

STEP 02

LivePlan（Servlet / JSP + MySQL）を開発

ライブ参戦スケジュールを登録・検索・管理する Web アプリを設計から実装まで

STEP 03

HTML / CSS / JavaScript に移植して公開

SQL を JSON に置き換え、GitHub Pages で動く静的アプリとして再実装
